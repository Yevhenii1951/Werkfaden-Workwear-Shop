# WW-000: Content package is machine-readable and validated before seeding

Status: in progress.

## Intent / delivers

The content package in `docs/content/` is the input to the WW-001 catalog seed. As received it could not be parsed by any JSON reader, and the self-report marked every check green without running a validator. This ticket makes the package parseable, removes one security contradiction, unifies the handoff keys and replaces the manual check with a real Zod validator plus unit tests.

It implements no FR of its own; it unblocks WW-001/WW-002, which own mapping and seeding per `../contract.md`.

## Blocked by

None.

## Complexity

Implementation: routine. Review: routine. Data-only repair plus a pure validation module; no admin surface, payments or uploads.

## Context to read

This ticket + ../contract.md + ../state.md.

## Verification scenario

GIVEN `docs/content/` as received WHEN the validator runs THEN it reports the three unparseable files and the SVG contradiction; AFTER the repair it parses all seven files, enforces 25 products / 150 variants / unique SKUs, and fails on any violation of the handoff contract.

## Acceptance criteria

- `products.json` parses as one array. Two opening brackets were lost, splitting 25 products into three chunks.
- `faq.json` parses. The final answer was truncated mid-string.
- `ui.de.json` parses. The `errors` block was truncated mid-key.
- No content recommends uploading SVG/EPS/AI. `faq.json`, `ui.de.json` and `pages.md` contradicted `spec.md` NFR-S2, which forbids SVG/PDF because of stored-XSS risk.
- `categories.json` exposes `category_id`, matching the key `products.json` uses to reference it.
- Zod schemas plus a validator live in `apps/backend/src/lib/content/` and fail closed.
- Unit tests cover the parse, the counts, unique SKUs, the product/variant price and stock agreement, and the raster-only upload rule.
- `docs/content/README.md` no longer claims `products.json` holds one product.
- Agent-authored German strings are marked as such in the validation report.

## Non-goals

No catalog seed, no product images, no import into Medusa. Rewriting the content author's product copy is out of scope; only broken syntax and the security contradiction are touched.
