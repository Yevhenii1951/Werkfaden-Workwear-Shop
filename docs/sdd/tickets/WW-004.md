## Verification scenario

GIVEN a cart with stock-limited items WHEN buyer changes quantity beyond stock or tampers with price THEN server rejects invalid quantity and never adopts browser price.

## Acceptance criteria

Add/update/remove; stale-price/stock handling; reject quantity and price tampering; avoid duplicate-line stock bypass.

## Non-goals

No wishlist or promotional pricing.

## Decision: use the template, do not re-implement core

The official DTC starter already ships cart add/update/remove server actions and the cart page. Medusa 2.21.2 core enforces the rest, verified against the installed packages:

- `add-to-cart` and `update-line-item-in-cart` call `confirmVariantInventoryWorkflow` with the summed quantity (existing line + change) and reject over-stock before persisting.
- Store route body validation runs first and rejects unknown fields such as `unit_price`; the line item price is always taken from the pricing module (`validateLineItemPricesStep`), so a browser price is never adopted.
- `quantity <= 0` is rejected by the request schema; `quantity: 0` on update removes the line (documented core behaviour).

An earlier revision added a custom `cart-stock` middleware with `cart-guards` and 21 unit tests. It duplicated core, and per `AGENTS.md` ("business logic belongs to workflows/module services") it was removed together with its tests. Error copy is Medusa's English text (decision: keep English for now).

## Known limitations (Medusa core, not our code)

- Fractional quantity passes the schema (`quantity: number().gt(0)`); `1.5` is accepted.
- Empty `variant_id` is not schema-validated for length; `POST /store/carts` with `variant_id: ""` returns HTTP 500 instead of 400.
- `POST /store/carts` with duplicate variant entries in `items` is confirmed per-entry, not aggregated (e.g. two entries that each fit but sum over stock are accepted).
- The cart endpoint does not return `inventory_quantity` for a line item's variant, so the quantity selector uses the template's fixed cap and the server remains the stock authority.
