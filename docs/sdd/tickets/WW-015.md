# WW-015: Distinct product card imagery and hero opacity

Status: complete (2026-10-19).

## Intent / delivers

Every product card in the catalog shows a distinct image instead of the shared
category placeholder, and the homepage hero media sits at a calmer 0.5 opacity.

- `apps/storefront/src/lib/util/product-images.ts` gains `PRODUCT_CARD_IMAGES`
  and `getProductCardImageUrl(handle, collection?)`: a per-product card image
  with the existing category list as fallback. `ProductPreview` and
  `StoreHits` (search results) both use it.
- 12 supplied PNGs converted to WebP under
  `apps/storefront/public/images/workwear/` (`jacken-1..3`, `hoodie-1..5`,
  `sweatshirt-1..4`), 1400 px long edge, quality 82.
- Hero background transparency raised: `wf-media-in` keyframe now ends at
  `opacity: 0.5` (`globals.css`).

## Blocked by

Nothing.

## Complexity

Implementation: low. Review: low — presentation-only, no data or money path.

## Context to read

This ticket + ../contract.md + ../state.md.

## Verification scenario

GIVEN a category listing page WHEN it renders THEN each product card shows a
different image and all images load; GIVEN the homepage hero WHEN the media
fade-in finishes THEN its computed opacity is 0.5.

## Acceptance criteria

- Every catalog product resolves a distinct card image; no repeats within a
  category page. Images are demo assets (Unsplash/generated), never presented
  as client photography.
- `getProductCardImageUrl` falls back to the category list, then to the Medusa
  thumbnail, so unknown handles still render.
- Hero media computed opacity is 0.5, reduced-motion still respected.
- `npm run check` green; no weakening of existing tests.

## Non-goals

No new photography sourcing, no PDP gallery changes beyond the existing
`getProductImageUrls`, no layout or typography changes.

## Checks / browser evidence

- Storefront `tsc --noEmit` clean; unit 29/29; lint passes with the 3
  pre-existing hook-dependency warnings.
- Browser (2026-10-19): all five category pages render 5/5 distinct images that
  load without error — `t-shirts`, `poloshirts`, `sweatshirts-hoodies`,
  `jacken-westen`, `arbeitshosen`. Home hero `.wf-hero-media` computed
  `opacity: 0.5`.
