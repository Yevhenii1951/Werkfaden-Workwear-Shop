## Intent / delivers

A German B2B workwear shop needs a contact page: address, phone, e-mail and a
map of the location. The project has no operator yet, so the page ships the
demo address of this Übungsprojekt in Kassel and says so on the page, in the
metadata and in the footer block.

The page lives at `/[countryCode]/kontakt`, is reachable from the footer
("Service & Konto" column + own "Kontakt (Demo)" column) and shows an
OpenStreetMap embed. The map is a plain iframe against
`openstreetmap.org/export/embed.html` - no API key and no cookies of its own.
The page names the third-party request under the map; the Impressum and
Datenschutz pages keep their placeholder state: this ticket does not invent
operator facts.

## Acceptance criteria

- `/[countryCode]/kontakt` renders with H1 "Kontakt", the demo address,
  "Erreichbarkeit" (phone + e-mail) and the demo notice
  "Nur zu Demo-/Übungszwecken".
- The map is an OpenStreetMap embed without an API key, with a link to the
  larger map; the iframe carries a descriptive title and loads lazily. The
  marker points to the Kassel city centre and the note under the map states
  that it stands for the fictional location.
- The page names the third-party request to openstreetmap.org under the map.
- The internal link to the quote form uses the localized client link (country
  code preserved, no redirect hop).
- The footer gains a "Kontakt (Demo)" column with the same data and a
  "Kontakt" entry in the link column; the grid adapts (5 columns on large
  screens).
- The page is guarded by the region check like the other storefront pages
  (unknown country code -> 404).
- Address, phone number, e-mail and the demo notice come from one shared
  source (`DEMO_COPY.contact`).
- Metadata carries title + description and the demo marker.
- Impressum and Datenschutz are unchanged.
- `npm run check` green; build green; browser evidence in the PR.

## Non-goals

No contact form with backend delivery, no real operator data, no phone
tracking, no Google Maps, no claim that the demo address is a real business.

## Known limits

- Address, phone number and e-mail are fictional. They are labelled as demo on
  the page and in the footer.
- The OSM embed is a third-party request to openstreetmap.org. It sets no
  cookies of its own, so no consent banner is required for it; the page names
  the request under the map and the iframe sends no referrer. A privacy
  statement that covers external embeds is still a legal task for a real
  launch.
