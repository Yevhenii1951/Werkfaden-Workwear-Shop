# Чек-лист для запуска (Launch Content Checklist)

_Внимание: Этот чек-лист предназначен для владельца бизнеса и разработчика. Он разделяет требования для Demo-портфолио и реального коммерческого запуска. LLM не предоставляет юридическую консультацию._

## 1. Юридические страницы и соответствие (Rechtliches)

- [ ] **Impressum:** Заменить все `[BETREIBER]`, `[ANSCHRIFT]`, `[KONTAKT]` на реальные, проверенные данные владельца. (Demo: использовать явные placeholders).
- [ ] **Datenschutzerklärung (DSGVO):** Актуализировать под реальные используемые сервисы (Stripe, хостинг, аналитика). Указать ответственного за обработку данных.
- [ ] **AGB:** Разработать с юристом. Включить пункты о переходе риска, сохранении права собственности, ограничениях ответственности.
- [ ] **Widerrufsbelehrung & Muster-Widerrufsformular:** Предоставить корректный шаблон для потребителей (B2C). Для B2B указать исключения.
- [ ] **Hinweis zu PSA:** Явно указать, что одежда НЕ является сертифицированной защитной экипировкой (keine zertifizierte PSA), если это так.

## 2. Операционные данные и налоги (Betrieb & Steuern)

- [ ] **USt-IdNr. и Steuernummer:** Проверить корректность отображения в футере и на счетах.
- [ ] **Цены и НДС:** Подтвердить, что все цены настроены как brutto с корректным расчетом 19% MwSt в Medusa.
- [ ] **Доставка:** Подтвердить реальные сроки (z.B. 3–5 Werktage) и стоимость (5,90 €). Настроить зоны доставки (только DE или расширить).
- [ ] **Склад и остатки:** Интегрировать реальную систему управления остатками. Удалить демо-значения (0, 1, 12 и т.д.).

## 3. Контент и права (Inhalt & Rechte)

- [ ] **Изображения:** Подтвердить наличие прав на использование (source_license) для всех сгенерированных или стоковых изображений. Удалить любые артефакты генерации (лишний текст, искаженные руки).
- [ ] **Составы тканей:** Заменить демонстрационные проценты (z.B. 85% Baumwolle) на реальные спецификации от поставщика.
- [ ] **Размерные сетки:** Заменить демо-таблицы на реальные замеры конкретных моделей производителя.
- [ ] **Veredelung (Нанесение):** Настроить реальный рабочий процесс получения файлов, проверки прав на логотип и выставления счетов.

## 4. Технические проверки (Technik)

- [ ] **Demo-Banner:** Удалить или скрыть баннер "Demo-Shop — keine echten Bestellungen oder Zahlungen" при переходе в Production.
- [ ] **Платежи:** Переключить Stripe с Testmode на Live-Mode. Проверить вебхуки.
- [ ] **Формы:** Проверить отправку реальных e-mail через транзакционный сервис (Resend/SendGrid) вместо заглушек.
- [ ] **Доступность (Accessibility):** Проверить контрастность цветов, alt-тексты у всех изображений и навигацию с клавиатуры.

## Разделение Demo и Live

| Компонент              | Demo-Portfolio                | Реальный запуск (Live)            |
| :--------------------- | :---------------------------- | :-------------------------------- |
| **Данные**             | Симулированные остатки и цены | Реальные данные из PIM/ERP        |
| **Платежи**            | Stripe Testmode               | Stripe Live-Mode + реальные шлюзы |
| **Юридические тексты** | Placeholders `[BETREIBER]`    | Проверенные юристом данные        |
| **Баннер**             | Видимый "Demo-Shop"           | Отсутствует                       |
| **Обработка заявок**   | Имитация отправки e-mail      | Реальная интеграция с CRM/почтой  |
