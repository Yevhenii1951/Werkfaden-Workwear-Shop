# WW-028: Karte lädt erst nach Einwilligung

Status: in progress (branch `fix/ww-028-map-consent`).

Surface: `S` (`apps/storefront`).

## Intent / delivers

Die Kontaktseite bettete eine OpenStreetMap-Karte sofort ein. Damit ging beim
bloßen Aufruf der Seite eine Verbindung samt IP-Adresse an einen Dritten, ohne
dass jemand gefragt wurde — auf einer Seite, die an anderer Stelle
Datenschutz ernst nimmt (Impressum, Datenschutz, Cookie-Hinweis auf technisch
notwendige Cookies beschränkt).

Geliefert: `contact-map.tsx` ist jetzt eine Client-Komponente, die zuerst eine
ruhige Fläche mit der Beschriftung „Interaktive Karte von OpenStreetMap“ und
einem Knopf „Karte laden“ zeigt. Erst der Klick setzt die `src` des `iframe`;
vorher existiert kein `iframe` und keine Anfrage an `openstreetmap.org`. Der
bestehende Link „Größere Karte auf OpenStreetMap anzeigen“ bleibt als
Alternative ohne Einbettung.

## Complexity

| Axis | Value | Why |
| --- | --- | --- |
| Implementation | low | ein Zustand, zwei Zweige |
| Verification | medium | „keine Anfrage vor dem Klick“ ist nur im Netzwerk-Log beweisbar |

## Context to read

Dieses Ticket + `../design.md` (Abschnitt Kontakt/Embeds) +
`apps/storefront/src/lib/content/demo-copy.ts` (`contact.mapNotice`, bereits
vorhanden und unverändert).

## Verification scenario

GIVEN die Seite `/de/kontakt` WHEN sie geladen wird THEN steht im DOM kein
`iframe` und im Netzwerk-Log keine Anfrage an `openstreetmap.org`; WHEN man
„Karte laden“ klickt THEN erscheint die Karte und der Marker steht am fiktiven
Standort in Kassel.

## Acceptance criteria

- Ohne Klick: kein `iframe` und keine Anfrage an einen Dritten.
- Der Knopf ist per Tastatur erreichbar und hat einen sichtbaren Fokus.
- Nach dem Klick lädt die Karte wie bisher (`loading="lazy"`,
  `referrerPolicy="no-referrer"`).
- Der Hinweistext zu OpenStreetMap bleibt sichtbar.
- `npm run check:ui`, `npm run build:ui` und voller `npm run check` grün.

## Non-goals

Kein Consent-Manager, kein Speichern der Entscheidung, keine Änderung an
Adresse, Marker oder Kartensprache, keine Änderung an Impressum/Datenschutz.

## Known limits

- Die Einwilligung gilt für den Seitenaufruf, nicht dauerhaft: nach einer
  Navigation beginnt die Seite wieder mit der Fläche. Ein echtes Opt-in würde
  eine gespeicherte Entscheidung brauchen.
- Nur diese eine Einbettung ist betroffen; andere Drittanbieter gibt es in der
  Storefront nicht.
