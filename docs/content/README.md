# Контент-пакет Werkfaden (Demo-Shop Portfolio)

Этот пакет содержит структурированные данные и тексты для демонстрационного интернет-магазина рабочей одежды на базе Medusa + Next.js. 
**Внимание:** Это портфолио. Магазин не ведёт реальную торговлю, все данные (цены, остатки, реквизиты) являются демонстрационными.

## Структура файлов
1. `brand.md` — Позиционирование, голос бренда, терминология.
2. `demo-policies.json` — Демонстрационные условия магазина (доставка, оплата, возвраты).
3. `categories.json` — 5 категорий товаров с SEO-данными.
4. `products.json` — Каталог из 25 продуктов (все 25 продуктов полностью представлены в файле).
5. `variants.csv` — Проверяемая таблица всех 150 вариантов (SKU).
6. `size-guides.json` — Демонстрационные таблицы размеров (tops, outerwear, trousers).
7. `buying-guide.md` — Инструкция по выбору размера и уходу за изделиями.
8. `pages.md` — Тексты основных страниц (Homepage, Über uns, Für Unternehmen и др.).
9. `faq.json` — 18 вопросов и ответов, согласованных с demo-policies.
10. `ui.de.json` — Словарь UI-текстов для интерфейса.
11. `emails.md` — 8 шаблонов транзакционных писем.
12. `image-manifest.json` — Манифест необходимых изображений.
13. `image-prompts.md` — Промпты для генерации изображений на английском языке.
14. `launch-content-checklist.md` — Чек-лист правовых и операционных вопросов для реального запуска.
15. `content-validation.md` — Отчёт о проверке согласованности данных.

## Важное предупреждение для разработчика
В интерфейсе магазина должен быть размещён заметный баннер: 
**"Demo-Shop — keine echten Bestellungen oder Zahlungen"**.
Все цены указаны в евроцентах (брутто, 19% MwSt). Не используйте эти данные для реальных юридических документов без замены placeholder'ов.
